# AgendaEmporium
Agenda feita para ajudar no gerenciamento da Emporium da Beleza.


## Como usar

- Clone o repositório
- Entre na pasta src
- Execute: 
    - python main.py
    - ou
    - py main.py

## Arquitetura
### src: arquivos gerais
- main.py: arquivo de teste
- artisan.py: arquivo de migrações e seeds, use -h para mais informações
### temp: arquivos temporários de documentação
